# Security Policy

## Reporting a vulnerability

Please do not report vulnerabilities in a public issue. Use a private GitHub Security Advisory for this repository. If that feature is unavailable, contact the Preferences AI organization administrators through a private channel and include:

- a concise description of the issue;
- the affected file or workflow;
- reproduction steps or a minimal proof of concept; and
- the potential impact.

Do not include live credentials or private user data in a report.

## Scope

Security reports may include:

- prompt-injection or unsafe-action instructions in the skill;
- malicious links, scripts, or executable content in skill references;
- workflows that expose secrets or grant unnecessary write permissions; and
- accidental publication of API keys, access tokens, wallet credentials, or user data.

The repository is public. Treat every committed file as visible to anyone, including fork authors and automated agents.
